# 场景与剧情动效清单

本轮动效分为两层：场景环境层持续表达地点、时辰与天候；剧情覆盖层只在事件进行时出现。两层均不拦截触控，位于立绘前、对话与 HUD 后。

## 场景动效（10/10）

- [x] 流樱过庭：36 枚前、中、远景 CSS 花瓣以三种尺寸分层下落、翻面与折返横移；凌霄殿、沈家大院、师妹住处的晴日时段触发。
- [x] 朔雪纷飞：大小两层雪粒以不同速度飘落；每九日一次的寒日于山门与林舍触发。
- [x] 灵雨如丝：18 条轻雨线斜落；户外场景遇「灵雨润畦」触发。
- [x] 骤雨横山：28 条快速雨线、低位水花与环境压暗；灵雨日中的指定骤雨日触发。
- [x] 日华穿云：由右上方投下四束会呼吸、缓慢偏移的体积光，配合局部曝光、日光辉斑与 14 枚浮尘；「金乌晴暖」的白昼户外触发。
- [x] 山岚漫阶：四层横向雾带缓慢游移；清晨山地场景触发。
- [x] 松叶随风：32 枚高对比金褐、苔绿叶片以前、中、远景三种尺寸翻转、摆动、折返坠落；林间小屋与田间小屋白昼触发。
- [x] 流萤照野：萤光点不规则明灭、横移；林舍、田地、灵田与酒楼夜间触发。
- [x] 炉星散火：火星从画面下方上升并熄灭；厨房、师姐住处和酒楼的暮夜触发。
- [x] 灵息浮尘：青蓝灵粒缓慢上浮；星辉夜里的听云居、凌霄殿、栖珍阁和情报局触发。

## 剧情动效（5/5）

- [x] 绯雾知心：粉色薄雾、柔光和少量花瓣；情缘、赠礼剧情触发。
- [x] 霜锋留痕：双层剑弧与定向碎光；沈清霜的相识、心事剧情触发。
- [x] 旧忆浮光：半透明记忆碎片缓慢浮游；彩蛋、触发点与普通特殊剧情触发。
- [x] 墨兆压境：四周墨色收拢、墨团上升；黑场开幕的危机或沉重剧情触发。
- [x] 金篆启章：双层金色法阵逆向旋转、符光浮动；主线剧情触发。

## 参考与取舍

- 樱花参考 [CSS-only Sakura Petals](https://codepen.io/BerylSky/pen/jOeMMXg) 的 CSS 几何花瓣与下落方式；没有采用 [WebGL Sakura Petals](https://codepen.io/lzhenry666/pen/ZEEVPMO) 的 WebGL 管线，以减少移动端持续渲染成本。
- 雨参考 [CSS Rain Effect](https://codepen.io/arickle/pen/XKjMZY) 的前后景雨线和落地溅点，改成固定数量元素，不在运行时持续创建 DOM。
- 雪参考 [Pure CSS Snow Fall](https://codepen.io/maremarismaria/pen/jOMmMRK) 的多层速度，改成 22 个实体雪粒，避免外部位图依赖。
- 落叶参考 [CSS Falling Leaves](https://codepen.io/uurrnn/pen/WNLVdN) 的三类横向轨迹和翻转节奏，并重绘为松褐、苔绿配色。
- 日光改为项目自有的方向性体积光方案：多束渐变光从右上投向场景主体，并以低频呼吸、轻微角度偏移和浮尘表达空气感；取消旋转日轮，避免像加载图标并减少视觉干扰。
- 雾参考 [Fog Mist Animation](https://codepen.io/gongchangco/pen/QWmGrwV) 的横向分层思路，改用本地渐变而不是外部雾图。
- 剧情烟雾参考 [CSS Smoke](https://codepen.io/jiwonson/pen/gZyYJm) 的左右交替上升轨迹；剑光参考 [CSS Samurai Animation](https://codepen.io/2xsamurai/pen/GvQpOj) 的短促斩击节奏，视觉全部重写为项目自身的仙侠语言。

## 性能与可访问性

- 只动画 `transform` 和 `opacity`，不使用逐帧 React 状态或持续增生的 DOM。
- 手机端自动裁减远景粒子；慢速刷新设备进一步减半。
- `prefers-reduced-motion` 下停止循环动画，仅保留静态氛围层。
- 动效层统一 `pointer-events: none`，不会遮挡人物、对话与操作按钮。
- 触发规则与动效元数据统一存放于 `app/game/vfx/effects-content.json`，展示组件不保存天气或剧情业务状态。
