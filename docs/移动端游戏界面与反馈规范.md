# 《槐安一梦》移动端游戏界面与反馈规范

## 页面框架

- 顶部安全区：地点/时辰、等级/经验、体力、灵石；只承载查看型状态。
- 中部场景区：每页唯一第一视觉焦点，优先显示人物、地图、水面、丹炉、田地或战场。
- 底部拇指区：一个主操作和最多两个次操作；危险操作移入确认层。
- 复杂管理：全屏二级页；临时选择：底部抽屉；重要结果：居中结算层。
- 返回统一在左上；关闭统一在右上；按钮有效触控区域至少 48px。

## 视觉变量

- 黛青：世界、普通面板与次按钮。
- 温金：当前目标、主操作、可领取与稀有奖励。
- 朱砂：危险、失败临界、覆盖与丢弃。
- 青玉：成长、恢复、可用状态。
- 墨灰：已完成、不可用与次级说明。
- 稀有度只改变边框、辉光和揭示等级，不牺牲名称与数值可读性。

## 反馈等级

1. 轻反馈：按压缩放、数字上浮、图标飞向资源栏；用于普通点击、拾取与状态变化。
2. 中反馈：局部光效、进度填充、入口高亮；用于阶段完成、装备升级和普通炼成。
3. 强反馈：背景压暗、短暂停顿、轮廓揭示、镜头与分层粒子；用于 Boss、突破、神品和关键剧情。
4. 危险反馈：朱砂提示、方向震动、明确原因与二次确认；禁止只显示“操作失败”。

## 性能与可访问性

- 主动画使用 `transform`、`opacity`，避免长期全屏滤镜。
- 限制同时存在的 DOM 粒子、水花和光点数量。
- 支持 `prefers-reduced-motion`，关闭循环辉光、抖动和装饰粒子。
- 状态不只靠颜色表达；按钮具备可见焦点、禁用条件和可读名称。
- 内容超长时优先分页/标签/详情抽屉，不制造多层纵向滚动。
