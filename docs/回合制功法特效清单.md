# 回合制功法与动作特效清单

本清单对应 `app/game/turn-combat/content/visuals.json`。每项功法保存独立的视觉家族、字印、主色、辅色和演出强度；React 特效层按家族生成不同轮廓与运动语义，持续效果绑定真实战斗状态和剩余回合数。

## 战斗指令界面

- [x] 常驻底部只保留当前招式摘要、施展键和五个核心指令，不再堆叠完整说明、全部功法与战术按钮。
- [x] 功法独立进入互斥底部抽屉，采用攻伐、护持、回元分类和横向招式轮盘。
- [x] 战术独立进入互斥底部抽屉，服丹、偷窃、逃跑均以大触控卡呈现。
- [x] 抽屉打开时仍保留战场上下文；回合结束自动收起，避免遮挡敌我状态。

## 基础动作

- [x] 试锋：墨色交叉剑痕、命中笔锋与伤害跳字。
- [x] 守中：青玉半弧护幕、架势回填与守势状态光环。
- [x] 调息：青绿气旋、恢复符光与气血/法力跳字。

## 攻伐与控制功法

- [x] 桃木飞剑：完整剑身、剑格、贯穿尾迹与火星，不再用斩线代替飞剑。
- [x] 千机弩：七道有错峰节奏的纵向弩矢雨。
- [x] 黑曲弓：拉弓、离弦箭体与命中准星三段反馈。
- [x] 修罗刀：血色月牙刀罡与独立血滴飞散。
- [x] 燕返术：两只燕形剪影俯冲并留下三道风线。
- [x] 灵蛇咒：八节蛇身、蛇首和蛇眼组成蜿蜒突进。
- [x] 火灵咒：赤橙火莲爆开与灼烧火星。
- [x] 行者法棍：纵向金棕棍影与落地冲击环。
- [x] 雪童子：冰蓝雪晶、霜环与迟滞冷雾。
- [x] 弑神八荒：宽幅紫黑虚空斩痕。
- [x] 天剑·无邪：金色天剑垂落与剑心闪光。
- [x] 魔剑·断魂：三重血红穿刺轨迹。
- [x] 游龙术：青色环游龙轨与群体压势环。
- [x] 阴阳盘：黑白两仪旋环与减益印记。
- [x] 幽冥刀：幽红追魂斩与重伤目标强调。
- [x] 天雷咒：蓝白雷柱、折线闪电与落雷停顿。
- [x] 玄刀阵：多层银灰刀阵交错绞杀。
- [x] 轮回法球：六道圆环、灰白法球与回生光点。

## 护持与回复功法

- [x] 护体金光：施法时金光罩展开；`fortified` 状态持续三回合，半圆透明罩随状态真实退场。
- [x] 地藏像：三重法相光轮、八瓣莲台、佛掌下压与治疗跳字。

## 新增战术动作

- [x] 服用丹药：底部丹药轮盘、滑动吸附、丹药功效详情与服用回元反馈。
- [x] 逃跑：显示实时身法成功率；成功与失败使用不同日志色和结算反馈。
- [x] 偷窃：显示实时妙手概率；成功时居中揭示灵石、宝物或功法残卷。

## 敌方动作

- [x] 掠影割：赤色快切。
- [x] 镇门撞：土金冲击。
- [x] 铁壁势：三片铆钉铁板自地面升起，与玩家的青玉半弧护幕完全区分。
- [x] 断岳斩：赤色重斩和危险预告。
- [x] 乱阵喝：红黑气浪。
- [x] 木臂回击：木色钝击。

## 视觉与性能约束

- [x] 每个视觉家族使用独立轻量 DOM 轮廓，同屏节点受控，动画以 `transform`、`opacity` 为主。
- [x] 减少动效模式会把动画压缩到近乎静止，不改变战斗数值和结算。
- [x] 敌人立绘加载失败时显示统一剪影兜底，不再留下空白角色位。
- [x] 初五山门战战前页直接展示迅影客、镇山客、断岳魁三张立绘。
