# 沈清霜「霜华心契」角色内容清单

## 人物口径

- [x] 以《师尊.txt》十四段参考为性格基底，但不照抄原台词。
- [x] 外在保持平静、克制、有威严；照料弟子时细致且不容敷衍。
- [x] 可爱来自笨拙、嘴硬、生活能力反差和被当场拆穿，不靠持续卖萌。
- [x] 病娇与占有欲作为压抑面存在，但明确区分“危险念头”和“实际选择”。
- [x] 她会吃醋、害怕和失控，也会学习询问、道歉、尊重拒绝与关系边界。
- [x] 对白采用自然口语和完整句，避免所有场景都写成文艺短句。
- [x] 威严、日常、可爱、吃醋、压抑、危险、脆弱与成熟关系均有独立场景承载。

## 日常对话库

- [x] 5档缘分：0—14、15—29、30—49、50—69、70—100。
- [x] 每档覆盖清晨、上午、午后、黄昏、夜晚、深夜六个时辰。
- [x] 每个“缘分×时辰”组合拥有7条轮换对白及独立结束语。
- [x] 日常轮换对白210条、环境补充对白20条，总计230条，且无完全重复。
- [x] 对话按真实缘分和当前游戏时辰选择，不在组件中写死。
- [x] 语料存放于独立文本资源 `app/game/content/shen-qingshuang-dialogue.json`。

## 五阶段渐进剧情

### 一·仍是师徒

- [x] 01「袖口的血」：威严检查伤势，建立“她总能看见你在硬撑”。
- [x] 02「多出来的早膳」：嘴硬准备蜜枣粥。
- [x] 03「罚练三遍」：公开严厉、私下偏心。
- [x] 04「一把伞的位置」：雨中并肩，第一次主动缩短距离。
- [x] 05「雪芽的喝法」：赠礼转化为共同喝茶的时间。
- [x] 06「灯为什么还亮着」：深夜等候，显露害怕空殿的压抑。

### 二·渐渐亲近

- [x] 07「拿错的书」：研究“如何让人回来”被当场抓包，含两次选择。
- [x] 08「榻边的粥」：守夜照料与嘴硬。
- [x] 09「下山申请」：从“不准”学习改成询问。
- [x] 10「补错的针脚」：笨拙缝衣与差点加入追踪符。
- [x] 11「没有下完的棋」：练习相信玩家会回来。
- [x] 12「月下只说闲话」：从不会闲聊到愿意听日常小事。

### 三·心意浮出

- [x] 13「太甜了」：桂花糕与口是心非。
- [x] 14「雨天洗衣」：藏衣念头真正越界后，她承认并道歉。
- [x] 15「门外的人」：偷听被发现的可爱反差。
- [x] 16「梅香来处」：吃醋、审问与玩家边界选择，含两次选择。

### 四·不再装作

- [x] 17「轮到她生病」：让一贯照顾人的她学习被照顾。
- [x] 18「宗主下山」：以普通人的身份约会。
- [x] 19「说到一半的话」：承认喜欢，并主动消除师尊身份压力。
- [x] 20「一杯就够」：微醺撒娇与私下称呼，含两次选择。
- [x] 21「锁门的梦」：直面占有欲，建立不监视、不代替决定的约定。
- [x] 22「发簪戴反了」：生活笨拙与亲密距离。
- [x] 23「山亭避雨」：怕雷的脆弱面。
- [x] 24「同心印」：把追踪能力主动删去，只留下危险感应。
- [x] 25「生辰面」：不过生辰的人期待一碗不圆的荷包蛋。
- [x] 26「别说不需要我」：发生争执、说清需求并修复关系，含两次选择。

### 五·往后日常

- [x] 27「今天谁做早饭」：烧糊粥后的共同分工。
- [x] 28「没有正事的一天」：不依靠危机推动的普通约会。
- [x] 29「没有寄出的信」：展示她不从容、却愿意沟通的一面。
- [x] 30「什么都没发生的夜晚」：安静共处也能形成亲密感。
- [x] 31「叫我的名字」：私下称呼完成关系身份转换。
- [x] 32「月落以后」：不是宏大誓言，而是约定把练剑、吃饭、争吵与和好一起过下去。

## 系统与节奏

- [x] 32段剧情全部存放在 `app/game/content/shen-qingshuang-events.json`。
- [x] 每段正文11—14轮，均处于要求的10—30轮范围。
- [x] 每段至少含一次玩家选择；其中5段含两次选择。
- [x] 覆盖场景进入、交谈、时辰变化、赠礼、检视、地图异闻、历法事件七种触发方式。
- [x] 后续剧情以前一段完成状态为前置，不会一次性堆叠触发。
- [x] 关键阶段加入缘分门槛；最低奖励路线也能自然跨过全部门槛。
- [x] 选择会改变缘分与人物记忆，但不以强制控制替代玩家意愿。
- [x] 终章接入统一功法和成长状态，奖励「天剑·无邪」。

## 调试与验收

- [x] 本地环境或显式 `?storyDebug=1` 参数下显示“剧情校验”按钮。

- [x] 可直接进入任意剧情的无效果副本，不增加缘分、不发奖励、不写完成记录。

- [x] `scripts/check-shen-content.mjs` 自动验证语料数量、时辰矩阵、对白长度、剧情轮数、选项、触发类型、顺序前置和最低好感路线。
