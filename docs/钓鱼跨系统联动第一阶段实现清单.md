# 钓鱼跨系统联动第一阶段实现清单

本阶段以《槐安-八系统28对联动设计-2026-09-28》为设计依据，只实现用户筛选后的前六组联动。原有钓鱼、农田、矿洞、畜牧、炼丹、功法和送礼逻辑保持不变；新增内容通过统一配置与联动服务叠加。

## 一、钓鱼 × 种地

- [x] 作物制饵：霜心草、碧落灵芝、赤霄龙葵可分别加工为三类饵团；一次加工得到三份，抛竿时消耗一份，并在水色、鱼影倾向和候选鱼群上产生可见变化。
- [x] 钓获种子：满足水域与钓获次数条件后，可钓到玄藻灵核或月魄莲子；种子直接写入灵田种匣，可立即播种。
- [x] 鱼类制肥：常见鱼获可在灵田沤制为鳞骨灵肥；肥料会同时缩短生长并提高产量，形成“鱼获消耗—农田增益”的完整循环。

## 二、钓鱼 × 挖矿

- [x] 矿石制作钓具：黑曜火铁、星陨铁、雷纹紫晶可以打造沉星坠与寻珍钩；钓具永久保存、可切换，并分别改变深层鱼与联动宝物的概率。
- [x] 矿洞发现钓点：累计挖开三块土后发现地脉镜潭；该地点永久写入钓点列表，可由矿洞直接前往。
- [x] 钓到矿洞线索：鱼腹矿纹拓片可在矿洞中消耗，用于揭示一条尚未开采的隐蔽支路；线索数量与使用结果持久化。

## 三、钓鱼 × 畜牧

- [x] 鱼类饲料：玉露灵蛙与月羽灵鸡可食用适合的常见鱼获；投喂复用灵兽偏爱饲料流程，实际推进成长、心情和产出，不对不适合的灵兽开放按钮。

## 四、钓鱼 × 炼丹

- [x] 鱼珠炼丹：珍稀鱼获可能伴随沧海鲛珠，鱼珠作为真实材料实例进入统一行囊，并可被炼丹配方消耗。
- [x] 钓获丹方：第五次有效钓获会发现《潮心护脉方》；发现后炼丹炉才加载该配方，可一键装填鱼珠、霜心草和玄水藻，炼成沧海护心丹。

## 五、钓鱼 × 人物属性或功法

- [x] 钓获完整功法：保留并接入原有第二次钓获《听澜引雷真诀》的机制；所得为完整功法物品，收入统一行囊后沿用既有研读、习得与战斗技能系统。

## 六、钓鱼 × 恋爱

- [x] 人物遗物：钓获霜白旧剑穗、醉月旧杯封后，可在对应人物交互中展示；展示增加关系、触发专属反应，但不会销毁收藏品，同一人物只触发一次。
- [x] 送鱼：送礼面板置顶展示人物偏好的已持有鱼获；送出后消耗真实鱼获、增加好感并推进一个关系阶段。
- [x] 人物提供钓点情报：达到关系要求后，花照影和柳知意会出现钓点情报选项；首次交谈永久解锁专属水域，再次选择会直接前往对应钓点。

## 模块边界

- `cross-system/content/fishing-links.json`：联动文案、材料、概率、人物偏好、解锁条件与地点配置。
- `cross-system/fishing-links.ts`：纯规则、筛选器、确定性随机与统一奖励描述。
- 各玩法组件：只负责展示和调用既有状态服务，不各自保存重复联动数据。
- `FishingProgress.links`：统一保存已发现内容、制成饵团、永久钓具、钓点、矿洞线索、遗物展示和人物情报状态。
