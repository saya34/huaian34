# 《槐安一梦》采集职业系统实现清单

> 标记规则：✓ 已实现并接入；X 本轮暂缓。本文同时作为后续维护的验收清单。

## 一、共用底层

- ✓ 把钓鱼、灵田、矿洞抽象为 `fishing / farming / mining` 三个采集职业。
- ✓ 建立独立职业状态：职业经验、职业等级、永久工具阶级、当前工具、图鉴、陈列、采集次数、加工次数。
- ✓ 建立 1—10 级职业经验曲线，并在三个玩法界面显示当前进度。
- ✓ 建立 1—5 阶永久工具体系；工具升级消耗灵石，不再把钓竿作为一次性消耗品。
- ✓ 建立稳定、寻珍、亲和、角色联携四类横向工具特性，并支持切换。
- ✓ 统一采集物稀有度为凡品、良品、珍品、玄品、仙品五档。
- ✓ 工具阶级限制可获取/培育的稀有度；高阶地点不存在低阶产物时自动保留最低可玩池，防止软锁。
- ✓ 统一主产物与伴生物结算：主产物稳定获得，伴生物基础 10%，由等级、工具阶级和特性提高，硬上限 25%。
- ✓ 稀有宝物位于伴生池内部，而不是额外叠加一条独立概率。
- ✓ 建立来源、用途、元素/性质标签；新增物品写入行囊时保留标签。
- ✓ 职业、工具、伴生物、加工配方、界面文案全部由独立 JSON 文本资源加载。
- ✓ 共用规则集中在 `gathering/engine.ts`，共用界面集中在 `GatheringCareerPanel.tsx`，三套玩法仅调用公共接口。

## 二、钓鱼职业

- ✓ 钓竿改为永久灵具；抛竿只消耗鱼饵/诱鱼散和当日定力。
- ✓ 保留常驻钓点、随机游光钓点、不同地点鱼池和差异概率。
- ✓ 保留动态收线、鱼力、张力、稀有鱼预兆与失败追回，不改成表格式交互。
- ✓ 工具阶级限制鱼获档位；灵饵、诱鱼散、职业等级和工具特性共同修正鱼池权重。
- ✓ “定波”工具降低收线难度；“亲和”工具强化高阶鱼权重。
- ✓ 鱼获同时写入职业图鉴，首次发现提供额外职业经验。
- ✓ 接入钓鱼伴生池：水鳞、听澜珠、古修遗钩、河图残片。
- ✓ 保留鱼获陈化、制饵、地点记录和河图残片玩法。
- ✓ 建立听澜水阁陈列界面，可将真实物品从行囊陈列或取回。

## 三、灵田职业

- ✓ 灵圃经验接入统一灵植师职业成长；收获同步记录图鉴和职业经验。
- ✓ 灵田/灵锄阶级限制高阶作物，界面明确显示解锁条件。
- ✓ 保留作物生长阶段、天气、灵泉、肥料、丰收、灵变和点击浮字动效。
- ✓ 每次成熟收获稳定返还一份对应灵种，避免基础生产链断裂。
- ✓ 接入灵田伴生池：百草灵露、五行花粉、灵变根须、地脉古种。
- ✓ 批量收获同样经过统一职业结算，不绕过经验、图鉴与伴生物规则。
- ✓ 建立跨职业加工：灵田产物可与水产、矿物共同制成诱鱼散、复苏壤和驱湿灵散。
- ✓ 建立百草温室图鉴/陈列界面。

## 四、矿洞职业

- ✓ 保留矿洞迷宫、相邻土块解锁、不同地层硬度、不可挖墙、钥匙宝箱和深层秘藏。
- ✓ 灵镐为永久工具，耐久归零后修理而非销毁。
- ✓ 统一五阶工具升级会同步旧矿洞的挖掘力与最大耐久，避免两套数值脱节。
- ✓ 每次获得矿物或藏宝图物品都写入寻脉师图鉴并提供职业经验。
- ✓ 接入矿洞伴生池：原生灵石屑、火脉晶核、古机括、太虚藏宝图残卷。
- ✓ 保留“越深越珍稀”、土块发现物品、宝箱、藏宝图合成与特殊副本入口。
- ✓ 建立矿物加工配方，并允许消耗灵田伴生材料制作淬锋镐头。
- ✓ 建立地脉珍藏室图鉴/陈列界面。

## 五、跨系统循环与防锁

- ✓ 钓鱼产物进入制饵、陈化、炼丹/世界需求标签链。
- ✓ 灵田产物进入肥料、诱鱼、炼丹和世界需求标签链。
- ✓ 矿物进入工具、设施、炼丹和藏宝图链。
- ✓ 三类职业至少各有一条跨职业配方，配方使用统一输入/输出结构。
- ✓ 收藏陈列消耗真实物品，取回后返还行囊，不复制资源。
- ✓ 低阶核心循环不依赖其他职业；跨职业材料用于增效和高阶加工，不形成基础软锁。
- ✓ 加工会消耗库存并记录次数/经验，避免材料只有来源没有回收口。

## 六、界面与资源

- ✓ 三个玩法都接入同一套黛青、旧纸、温金职业面板。
- ✓ 面板包含职业等级、经验条、永久工具、横向特性、下一阶解锁、加工、图鉴与陈列。
- ✓ 移动端自动改为单列工具卡并限制内部滚动高度，避免遮挡主玩法。
- ✓ 复用现有仙草、矿石、遗物图片，新增伴生物均绑定图片资源，不出现纯文字占位。
- ✓ 新增的数值、名称、描述、配方和界面文字均与执行代码分离。

## 七、本轮暂缓

- X 为每一件陈列物制作独立 3D/骨骼动画模型：当前 H5 项目采用 2D 美术体系，先用带稀有光效的实物陈列卡实现。
- X 完整采集职业专属任务链：任务系统接口已经存在，但附件没有提供剧情与验收文本；本轮先完成可供任务读取的职业状态与物品标签。
- X 全部旧有钓鱼、农田、矿洞定义迁移为 JSON：本轮新增共用层及所有新增数据已资源化；旧定义继续保留以降低一次性回归风险，后续可逐模块迁移。

## 九、验收路径

1. 打开常驻钓点，确认钓竿显示为永久灵具，抛竿后仅鱼饵减少；成功收线后职业经验和图鉴更新。
2. 打开灵田，收获成熟作物，确认返种、职业经验、图鉴与伴生结算；使用批量收获再验证一次。
3. 打开常驻矿洞，挖出矿物或开启宝箱，确认寻脉师经验和图鉴更新；灵镐仍可修复。
4. 在任一职业面板切换“灵具 / 加工 / 珍藏”，验证升级、材料校验、加工消耗、陈列与取回。
5. 刷新页面，确认三个职业的经验、工具、图鉴和陈列状态均保留。
