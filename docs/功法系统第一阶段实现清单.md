# 功法系统第一阶段实现清单

## 万法谱

- [x] 功法无前后依赖，统一由剧情、随机事件、商店和副本掉落取得。
- [x] 已取得功法进入秘境升级“三选一”候选池。
- [x] 功法名称、立绘、流派、品质、来源与描述由独立 JSON 素材加载。
- [x] 新增流派转轮、玉简陈列、功法主视觉和修习反馈。
- [x] 悟道残卷可提升单本功法外修境界，并真实提高该系战斗伤害。
- [x] 未取得功法只显示获得线索，不能通过等级按钮直接绕过获取流程。

## 天衍道脉

- [x] 建立杀伐、护生、问宝三种入口。
- [x] 每条道脉有两个可选分支，每条分支由根节点延伸至第 12 层。
- [x] 后置节点必须在前置节点习得后才能点亮。
- [x] 每隔三个节点设置一个强力节点。
- [x] 悟道点与人物等级共用权威成长状态，每级提供一点。
- [x] 被动属性进入统一永久属性计算。
- [x] 复活、强制撤离、撤离加速、奖励重选、寻宝权重等规则进入战斗引擎。
- [x] 双重效果节点支持多条属性与机制同时生效，避免文案与实效不一致。
- [x] 三条道脉及全部节点数据由独立 JSON 素材加载。

## UI、动效与美术

- [x] 新增修真山河道脉背景素材。
- [x] 三种道脉使用独立色相、徽记和选中反馈。
- [x] 普通节点、强力节点、可点亮、已点亮与锁定状态具备不同视觉层级。
- [x] 强力节点点亮采用更高等级的居中反馈，普通节点采用轻反馈。
- [x] 手机端使用横向道脉卷轴，底部保留当前节点与主操作，避免把 13 层压成表格。
- [x] 支持减少动效模式。
